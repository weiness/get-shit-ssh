## Overview

GSS 首个公开发布版本。一款基于 Go + React + Wails 构建的轻量级桌面 SSH 客户端，面向 Windows 和 macOS 平台，支持多标签终端、SFTP 文件管理和 SSH 密钥管理。

## Milestone Summary

**Key Decisions:**
- Wails v2 替代 Electron——体积更小，无额外 Node 运行时
- SQLite modernc（纯 Go）——无 CGO，跨平台编译零阻力
- 手动 CHANGELOG + awk 提取——比 GitHub 自动生成的 release notes 可读性更好
- 移除 Linux 构建目标——减少 CI 复杂度，聚焦主要用户平台

**Issues Resolved:**
- awk range pattern 在单版本 CHANGELOG 时失效——改用有状态逐行匹配
- CI publish job 缺少 job 级 `permissions: contents: write`——导致静默失败
- `git filter-repo` 不支持 `--mailmap-filename`——改用 Python callback lambda
- tag 冲突（本地 + 远程均存在）——先删后建的标准流程

**Technical Debt Incurred:**
- `app.go` 加密密钥硬编码为 32 字节零值（`make([]byte, 32)`），需 v1.1 改为从安全密钥库加载
- 主机密钥验证为 `InsecureIgnoreHostKey`——已在 README 安全说明中注明，计划 v1.1 实现严格验证
